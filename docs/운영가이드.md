# 운영 가이드

설치는 [`README.md`](../README.md). 이 문서는 **설치 후 매 시식마다 하는 일**입니다.

## 1. 새 시식 회차 만들기

1. 응답 주소 끝에 `#admin` → 비밀번호 → **⚙️ 관리**
2. 브랜드가 없으면 **브랜드 관리 → + 브랜드 등록** (제품에 붙는 이름표·색. 시식 회차에만 쓰임)
3. **`+ 새 시식`** — *지금 활성인 회차(없으면 가장 최근 회차)를 복제*해서 시작합니다(제품·항목 이름까지 이어짐).
4. 회차 ID(자동 제안값 수정 가능)·제목·소개 문구 입력
5. **제품** 추가(`+ 제품`): **브랜드 칩**(여러 개 선택 가능) + 제품명 + 태그(예: `홀버전·1인 그릇`). 제품 이름은 서로 달라야 함(같으면 점수가 섞여 저장이 막힘)
   - **공통 메뉴**(여러 브랜드가 함께 출시): 브랜드 칩을 **둘 이상** 켠다(예: 과메기 → 삼대미역 + 어화락). 하나는 반드시 켜져 있어야 한다.
     결과 화면의 브랜드 필터·브랜드별 PDF 에서 **그 브랜드들 모두에** 포함돼 나오고, 랭킹·보고서에는 `삼대미역·어화락`으로 표시된다.
6. (선택) **평가 항목 이름** 수정 → 4번 항목 참고
7. **문항**(`+ 문항`, 제품과 무관한 회차 전체 질문) 추가: 선택 투표(버튼형/목록형)·사진 투표·자유 의견·추가 의견
   - 선택지는 **한 줄에 하나씩** 입력(쉼표로 나누면 `10,000원` 같은 값이 깨짐)
   - **자유 의견 + 제목 띠**: 자유 의견 문항의 `제목 띠(선택)` 칸에 제목을 적으면 **제목 + 질문 문구(작은 글씨) + 입력칸**이 한 묶음으로 나온다(별도 구분 제목 불필요). 예) 제목 `종합 정리`, 질문 문구 `오늘 시식하신 메뉴에 대한 의견을 자유롭게 남겨주세요`. 결과·PDF·엑셀에는 영향이 없다(질문 문구가 열 이름).
   - **필수 응답**: 선택·사진 투표는 기본 필수(끄면 건너뛸 수 있음), **자유 의견은 기본 선택이고 `필수 응답`을 켜면** 비워 둔 채 제출할 수 없다(공백만 넣어도 입력으로 치지 않음, 제목 띠 형태에서는 제목 옆에 `*`). 진행 막대에도 반영된다. `추가 의견`은 항상 선택이다.
   - 제품·문항·구분 제목 카드의 **`⧉ 복사`** 버튼: 바로 아래에 같은 내용으로 복사한다(문항은 새 내부 ID라 응답이 섞이지 않고 문구 뒤에 `(복사)` 가 붙는다. 제품은 이름이 겹치면 점수가 섞이므로 `(복사)` 이름으로 만든다 — 바로 고쳐서 쓸 것).
   - **구분 제목**(`문항 유형 → 구분 제목`): 질문이 아니라 화면에 제목 띠만 넣는다(번호 없음). 앞 문항 묶음과 뒤 문항 묶음을 시각적으로 나눌 때 쓴다.
     예) `반찬 3종 투표` 다음에 `전체 메뉴 공통 질문`을 넣으면 "제공된 음식의 온도"가 반찬에만 해당하는 것처럼 보이지 않는다.
     결과 화면·PDF·엑셀의 투표 집계도 이 제목별로 묶여 나온다.
   - **투표 문항의 소속 규칙 (하나뿐)** — **바로 앞에 있는 제품 또는 구분 제목**이 소속을 정한다. 결과 화면 필터·PDF·엑셀 `문항 집계`의 `소속` 열이 모두 같다.
     ① 바로 앞이 **제품**이면 그 제품의 브랜드(공통 메뉴면 여러 브랜드) — 예: `과메기 → 과메기 구매 의향` 은 과메기의 브랜드들 소속, 그 뒤에 이어지는 문항도 계속 같은 소속
     ② 바로 앞이 **구분 제목**이면 그 제목에 지정한 브랜드(`소속 브랜드(선택)` 칩), 지정이 없으면 **공통**
     ③ 맨 앞(아무것도 없음)은 공통.
     ④ 문항마다 **`공통 질문으로 분리`** 를 켜면 위치와 상관없이 **공통**(응답 폼에서의 위치·순서는 그대로, 결과·PDF·엑셀에서만 앞 메뉴에서 떨어짐). 문항 카드 아래의 `결과 소속 → …` 줄에서 지금 어디에 붙어 있는지 바로 확인할 수 있다. 끄면 다시 ①~③ 규칙을 따른다.
     → 전체 메뉴에 대한 질문(가성비·재구매 등)은 **구분 제목으로 끊어 주면** 공통이 된다. 응답자 전체 기준 투표라 어느 브랜드 것이 아니므로 **전체 보고서에 한 번만** 나온다.
- **화면 배치**: 화면 폭을 넓게(최대 1640px) 써서 **윗줄 = 제품 상세 | 종합 의견**, **아랫줄 = 왼쪽(제품 랭킹·판정 → 선택·투표 집계) | 오른쪽(세그먼트×항목 히트맵)** 으로 둔다.
  종합 의견은 제품 상세와 같은 높이의 카드 안에서 **따로 스크롤**되고 최근 30건까지 보인다(그 이상은 PDF·엑셀). 화면 폭 1000px 미만에서는 제품 상세 → 랭킹 → 히트맵 → 투표 → 의견 순으로 한 줄로 쌓인다.
  (제품 상세 옆에 의견이 붙어 있어, 큰 모니터에서는 첫 화면에 제품 상세와 의견이 함께 보인다. 모든 내용을 스크롤 없이 한 화면에 넣는 것은 내용이 길어 불가능하다.)
- **제품 상세**(레이더·항목별 평균) → **제품 랭킹·판정** → 연령대×항목 히트맵 → 의견 → 문항별 집계
- 15초마다 자동 갱신
- **📄 보고서(PDF)**: 새 창이 열리면 인쇄 → PDF 로 저장. 보고서는 **브랜드가 아니라 "메뉴 묶음"** 기준으로 구성된다 — 같은 제품·같은 투표가 두 번 나오지 않는다.
  1. **요약(한 번만)**: 응답 수·1위 제품 KPI, `구성`(공통 메뉴 N종 / ○○ 전용 N종), `판정 요약`, 📌 핵심 결과, 전체 제품 랭킹·판정
  2. **공통 메뉴 구역**(브랜드 2개 이상이 함께 파는 메뉴) → **○○ 전용 구역**: 각 구역에 *제품별 항목 평균*(제품 이름 아래에 맛·관능·판정을 작게 표시)과 *그 메뉴의 투표*가 함께 들어간다
  3. **공통 질문**(소속 없는 투표) → **응답자 구성** → **종합 의견**
  - 창 오른쪽 위 **보고서 범위**: `전체` / `○○ 관련`(= 전체에서 다른 브랜드 전용 구역만 뺀 것. 공통 메뉴 결과는 다른 브랜드 파일에도 똑같이 들어감) / `투표·의견만`. PDF 기본 파일명에 범위가 붙는다(예: `…_어화락관련_결과보고서`).
  - 구역이 하나뿐이면(브랜드 1개이거나 모든 제품이 공통) 구역 구분·범위 선택 없이 한 덩어리로 나온다.
  - 표·투표 한 문항·의견 묶음은 쪽 중간에서 쪼개지지 않게 설정돼 있다. **인쇄 대화상자에서 배율 100%, 여백 기본**을 권장.
- **📊 엑셀 저장**: `.xlsx` — 요약(제품 랭킹·판정) / 세그먼트(연령·성별별 평균) / 문항 집계 / 응답 원자료 / 자유 의견. 헤더는 실제 질문 문구, 점수는 숫자, 시각은 현지 시각. 라이브러리를 못 불러오면 CSV 로 자동 대체

## 6. 회차 정리

| 하고 싶은 일 | 방법 |
|---|---|
| 목록에서 치우기 | 관리 → 회차 목록 → **숨기기**(삭제 아님. 결과 조회·복원 가능) |
| 되살리기 | 목록 하단 **보관한 회차 → 복원** |
| **영구 삭제**(되돌릴 수 없음) | 웹에서는 **불가능**하게 막아 둠. Supabase SQL Editor 에서 [`supabase/maintenance.sql`](../supabase/maintenance.sql) ④ 블록으로만 |
| 테스트 응답 정리 | 실제 제출 테스트는 **별도 테스트 회차**에서 하고, 끝나면 위 영구 삭제로 정리 |

## 7. 알려진 한계

- **중복 응답을 막지 못함**: 익명 제출이라 한 사람이 여러 번 낼 수 있음. 표본을 늘려 신뢰도를 올리려는 시식에서는 현장 진행자가 1인 1회를 안내하세요.
- **복수선택(체크박스) 문항 없음**: 선택 문항은 전부 하나만 고르는 방식.
- **문항은 회차 전체 대상**: "제품별로 따로 묻는 문항"은 없음(제품별로는 8개 평가 항목만).
- **5축(구형) 회차와 8축 회차는 합산 불가**: 서로 다른 질문에 답한 데이터라 숫자가 왜곡됩니다. 같은 8축 구성 회차끼리만 합산 가능하며, **회차 합산 보기 화면은 아직 없음**.
- **한 화면에 최대 1000건**: Supabase 기본 조회 한도(보통 1000건) 때문에 응답이 그보다 많은 회차는 결과가 잘립니다.
- **활성 회차를 비워 두지 말 것**: 활성 회차가 없으면 응답 주소를 여는 순간 `questions.json` 샘플 회차가 자동 생성·활성화됩니다.
